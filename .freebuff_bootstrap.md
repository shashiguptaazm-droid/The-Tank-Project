## 1. Architecture (Full Pipeline)

```
User Input
    │
    ▼
┌─────────────────────────────────────────────────┐
│  TerminalREPL (cli.py) — cmd.Cmd loop           │
│  │                                               │
│  ├─ "!ls -la" → Direct shell bypass             │
│  ├─ "list files" → AIRouter (ai_router.py)      │
│  │      │                                        │
│  │      ▼                                        │
│  │  AIManager.chat() (ai_manager.py)             │
│  │      │                                        │
│  │      ▼                                        │
│  │  RotationAdapter (evolution_bridge.py)        │
│  │      │                                        │
│  │      ▼                                        │
│  │  RotationOrchestrator → 12 evolution providers│
│  │      │  (Groq→Mistral→Cohere→... fallback)    │
│  │      ▼                                        │
│  │  LLM returns: {"command": "ls *.py"}         │
│  │      │                                        │
│  │  ┌──── AI FAILED? ──→ ToolRegistry.search()  │
│  │  │                    → Show tool suggestions │
│  │  └──── AI OK? ──────→ Use AI command          │
│  │                                               │
│  └─ Safety classify → Shell execute → Output     │
└─────────────────────────────────────────────────┘
```
