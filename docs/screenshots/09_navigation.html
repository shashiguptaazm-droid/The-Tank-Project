Autonomous Navigation System

Features

  • Occupancy Grid SLAM (100x100, 0.1m resolution)
  • A* Path Planning with obstacle inflation
  • VFH Obstacle Avoidance (vector field histogram)
  • 4 Modes: Autonomous, Go-to-Goal, Patrol, Return-Home
  • Encoder odometry + LiDAR fusion

Navigation Commands

nav.go_to_goal(x, y) - Navigate to coordinate
nav.return_home() - Return to dock
nav.start_patrol(waypoints) - Patrol mode
nav.emergency_stop() - E-stop
