# 🌐 TankOS i18n — Language Support for Everyone

> **16 languages, packs hosted on the VPS, device stays light, works offline.**

TankOS speaks your language. The GUI ships with **16 languages** (English +
15 translations) and every pack lives on the **VPS** (`medicscholar`), not on
the robot — so the device's storage stays small and adding a language never
requires a device update.

```
┌─────────────┐   fetch on demand    ┌──────────────────────┐
│  TankOS GUI │ ───────────────────▶ │ VPS /lang/{code}.json │
│ (UNO Q/… )  │ ◀─────────────────── │  nginx static (tailnet │
└──────┬──────┘    cached locally    │  + public IP)         │
       │                             └──────────────────────┘
       ▼
~/.cache/tankos/lang/{code}.json   ← offline-first: last pack always works
```

## Design

**`tank_os/core/i18n.py`** — the `I18nManager` singleton:

| Piece | What it does |
|---|---|
| `set_language(code)` | Switch the active language; falls back to English when a pack is unknown |
| `t("Home")` / `t(key)` | Translate an English source string into the current language (module-level helper) |
| `sync(code=None)` | Download pack(s) from the VPS into the local cache — `None` syncs all 16 |
| `sync_async()` | Background thread — never blocks the GUI |
| `translate_widget_tree(widget)` | Walk a Qt widget tree and swap exact-match English labels — existing screens localize without being rewritten |
| `status()` | Current language, cached packs, mirrors |

**Offline-first:** a small built-in English pack means the GUI never depends on
the network; once a pack is fetched it's cached under
`~/.cache/tankos/lang/` and keeps working when the VPS is unreachable.

## VPS hosting

- Packs are generated by `scripts/langgen.py` (45 keys: dock labels, settings
  sections, common status strings) and uploaded to
  `/var/www/html/lang/{code}.json` on the VPS.
- Served by nginx over **both** the tailnet IP (`100.71.127.19/lang/…`) and
  the public IP (`213.199.61.156/lang/…`) — verified HTTP 200 on both.
- The manager tries mirrors in order, so the device works on the mesh or over
  the internet.

## GUI

- **Settings → 🌐 Language** — a dropdown with all 16 languages (flag + native
  name), a **⬇ Sync Language Packs (from VPS)** button, and a status line
  (`N cached · packs on VPS`). Switching applies instantly and persists.
- **BottomDock** — all dock labels re-translate when the language changes,
  and the persisted language is applied at shell boot.
- Screens opt into `t()` for fine control, or rely on the
  `translate_widget_tree` pass that runs on `language_changed` events.

## Adding a language

1. Add translations in `scripts/langgen.py` (`PACKS[code] = {...}`).
2. Add the metadata row to `LANGUAGES` in `tank_os/core/i18n.py`.
3. Run `python3 scripts/langgen.py --upload` — the pack is live on the VPS
   and available to every device without any device-side update.
